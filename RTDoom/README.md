# RTDoom website

Public site: https://renegade-android.github.io/RTDoom/
Public repository: https://github.com/RENEGADE-ANDROiD/RENEGADE-ANDROiD.github.io

Only static website files and captured media are published. Engine source and
runtime checkpoints remain in the private RTDoom development repository.
No game data, executable, DLL, archive, personal configuration or credential
is included in the public website repository.

Media: ten screenshots and two 1080p H.264 clips from twelve separate Doom II
maps in the native reference preview. Cursor capture is disabled. Still images
are lossless WebP with pixel equality checked against the PNG masters. See
credits.html for camera, lighting, materials and performance context.

The root github.io page redirects to /RTDoom/. The GitHub repository view links
to the website; GitHub does not allow that repository view to auto-redirect.
