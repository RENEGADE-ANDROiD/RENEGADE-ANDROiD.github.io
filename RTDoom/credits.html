PROJECT NOTES

Credits & captures.

RTDoom is an independent engine fork developed by RENEGADE-ANDROiD. It retains the licenses and acknowledgments of its upstream projects.

The engine lineage

  • UZDoom, built on GZDoom and ZDoom.
  • GZDoom RT and RTGL, including the ray-traced renderer originally developed by Sultim Tsyrendashiev.
  • CynicGames’ SuperShadersSuite visual features, integrated with their retained MIT license and individual shader credits.
  • AMD FidelityFX for FSR upscaling, plus the other libraries credited in the engine source.

What the media shows

Ten screenshots and two recordings show twelve different stock Doom II maps in the updated RTDoom native reference preview. Captures are 1920 × 1080, with FSR 3.1.4 Quality upscaling from 1280 × 720. Frame generation is off. The mouse cursor was excluded from capture and mouse input was disabled.

This development preview uses selected authored lighting scenes and native material maps from GZDoom RT. No model replacements or gameplay addons were loaded. Monsters were disabled, and photo cameras were positioned with console controls. Exposure, sky lighting and fog were tuned for each scene; these are visual examples, not performance benchmarks or a claim about every map’s default appearance.

Still images use lossless WebP encoding with verified pixel parity to the captured PNG masters. Videos use H.264 at 1080p and 20 frames per second. Original captures are retained locally. The updated fog grid has 75% fewer cells than the preceding full grid; actual frame rate still depends on hardware and workload.

Development status

The current source and tools are backed up in a private development repository. The public build is still being prepared. A release must include the appropriate licenses and corresponding source for GPL-covered components. The website does not currently distribute an engine build or game data.

Mod compatibility is a development goal. Broad compatibility, older saves, large maps and combat performance remain under testing. “60 FPS Target” is a preset name, not a guaranteed frame rate on every system.
