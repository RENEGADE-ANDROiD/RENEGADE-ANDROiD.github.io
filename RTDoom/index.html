ATMOSPHERE AND REFLECTIONS

Below the surface.

Water catches the room’s light while fog adds depth to the tunnels. Color, density and drift can be adjusted in the client.

Optional volumetric lighting costs more than distant haze. The updated renderer uses a smaller fog grid to reduce that work.

BUILT INTO THE CLIENT

RT Presets.
One place to tune the look.

Open Options → RT Presets for rendering quality, visual styles, lighting, darkness and fog. The integrated features no longer need SuperShadersSuiteRT in the addon list.

Quality choices
Native, Quality, Performance and 60 FPS Target. Bounced lighting and reflections stay enabled; the presets adjust rendering resolution and ray depth.

A cleaner image
FSR 3.1 upscaling and a Clean image option. Integrated styles remain available when you want a different look.

Performance matters
Default haze skips the volumetric ray and 3D integration work used by shafts. Frame rate still depends on hardware, maps and combat.

RTDoom is a community engine project, free to use. The current development checkpoint is backed up privately. Downloads and corresponding source will be linked here when the release is ready. This public repository contains website files only.

No game data is bundled. You will need your own compatible Doom IWAD, 64-bit Windows and a GPU with Vulkan ray-tracing support.

What is being checked

  • Lighting and material behavior across maps
  • Mod compatibility and saves
  • Performance during movement and combat
  • Packaging and source availability
